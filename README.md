# ItemCloud Smart Locker System

## Overview

ItemCloud is a smart locker system designed to automate the lost-and-found process through web technologies, cloud services, and IoT hardware integration.

## Team Project

This project was developed collaboratively as a team.

## My Contributions

- Hardware implementation
- Physical prototype construction
- Component integration
- Wiring and assembly
- Sensor testing
- Troubleshooting
- Real-world deployment preparation

## Technologies Used

- ESP32
- ESP32-CAM
- Ultrasonic Sensors
- IR Sensors
- Solenoid Locks
- Firebase
- Web Technologies
